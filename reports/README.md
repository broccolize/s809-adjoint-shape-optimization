# Original report

`s809-case-study-original.pdf` is an unchanged copy of the supplied **Aerodynamic Shape Optimization of the NREL S809 Wind-Turbine Airfoil** report, authored by Mineth Ariyarathna for Aerodynamics I. The report bears a 3 July 2026 submission date; the repository does not infer the work period from that timestamp.

Keep the report as a historical study artifact. The root README and `docs/results-audit.md` provide a more conservative interpretation of mesh sensitivity, finite trim tolerance, and differences between the two cases. The original PDF is not silently rewritten to match the later analysis. Figure source PNGs are retained where available; the lightweight audit regenerates only its four summary figures, not the full report or solved flow fields.
